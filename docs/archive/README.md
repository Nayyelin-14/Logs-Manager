- `DATABASE_MIGRATION_PLAN.md` — superseded migration planning notes

- `stitch-page-by-page-guide.md` — superseded frontend design walkthrough
- `PHASES_COMPLETION_REPORT.md` — superseded backend phase report
- `SESSION_HANDOVER.md` — superseded session handover notes
- Existing archive files (`MIGRATION_ROADMAP.md`, `PRISMA_MIGRATIONS.md`, `PROJECT_AUDIT.md`) — pre-existing historical material

Reviewer-facing current docs live in `docs/` (architecture, setup guides, schema, demo guide, API contract, security design, and final report). Archived documents may describe outdated endpoints, roles, OTP flows, deployment scripts, or test counts and should not be used as the authoritative reference.
